# Adaptive Learning Rules

## Accuracy gates

- `< 90%`: reduce difficulty and focus on precision.
- `90–96%`: maintain difficulty and repeat targeted practice.
- `>= 97%`: permit small difficulty increases when consistency is stable.

## Persistence rule

A weakness should not become a major curriculum decision from one noisy session. Prefer repeated evidence across multiple sessions.

## Speed rule

Never optimize WPM independently from accuracy. A speed increase that causes substantial accuracy regression is not progress.

## Mastery rule

A skill is not mastered because the learner once achieved a high score. Require repeated successful sessions or another explicit mastery criterion.

## Exercise rule

Every generated exercise must have a declared target skill and a validation result.

## Coaching rule

Explain one priority first. Use secondary observations only when they materially improve the user's next action.
