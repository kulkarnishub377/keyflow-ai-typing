# Requirements & Compliance Runbook

## 1. Roadmap Verification
- When a new feature is requested (e.g., "Add hand balance analysis"), cross-reference `AI_ROADMAP.md`. 
- Is it a Stage 1 or Stage 2 feature? If it's Stage 4, push back and require prerequisites.

## 2. UX Compliance
- Check the proposed feature against `04-adaptive-learning.md`. 
- Does it prioritize accuracy over WPM? 
- Is the coaching feedback actionable?
- If the feature introduces gamification (e.g., "Killstreaks"), flag it. KeyFlow is a deliberate practice tool, not an arcade game.
